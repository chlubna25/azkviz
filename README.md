# AZ kvíz

Jednoduchá webová aplikace AZ kvízu. Vhodná na zpestření školních hodin a různých akcí.

## Dostupnost

AZ kvíz je volně k dispozici na https://chlubna25.github.io/azkviz/

Stačí načíst otázky a začít hrát :)

## CSV formát

Aplikace očekává přesně 28 otázek. Otázky nejsou vůbec randomizované.

```csv
label;question;answer;yes_no_question;yes_no_answer
A;Jaké je hlavní město České republiky?;Praha;Leží Praha na řece Vltavě?;ANO
```
